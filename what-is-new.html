New Features: Conferences in Theoretical Computer Science

New features

  • We changed the background. It is now white instead of green.
  • The focused lines are highlighted in light blue color.
  • We introduced two kinds of sticky headers.
  • The main sticky header allows you to jump between sections and also indicates the section which you are visiting.
  • The subordinate one is the sticky header of the section indicating conference items.
  • We suppressed column colors, because conference items are now visible through sticky headers.
  • Hover over conference acronym. A tooltip gives you the full name of the conference.
  • Hover over deadlines and notifications. A tooltip gives you the details of the dates.
  • We designed a new interactive page for collecting conference information from organizers.
  • Internally, the information on conferences is now stored in a JSON file and not in the main HTML file.
  • The web page is populated by JavaScript from the coresponding JSON file.
  • Assignment of conferences to the three main sections (Deadline, Upcoming, and Running) is done automatically, according to dates.
  • If you found an error or if you have a remark, please contact us.
